# StockPriceDetection
This project predicts stock prices using historical data with machine learning models like Random Forest and SVR. After preprocessing and feature engineering, models accurately forecast closing prices. The work shows machine learning’s potential in finance and suggests future improvements like sentiment analysis and advanced deep learning models.
The Stock Price Prediction project focuses on forecasting the future prices of stocks using historical market data. Stock price forecasting is valuable for investors and financial analysts as it assists in making informed investment decisions, managing risks, and maximizing returns. However, the task is challenging due to the volatile and non-linear nature of stock markets, influenced by various factors such as market sentiment, economic indicators, and global events.

The objective of this project is to develop a machine learning model that predicts the closing price of a stock based on past market data. The dataset used comprises historical stock information, including features like Open, High, Low, Close prices, and Volume of shares traded, collected over a specific time frame from financial sources.

The project began with **exploratory data analysis** (EDA) to understand trends and relationships in the dataset. Line charts and descriptive statistics were used to visualize and summarize data patterns. In the **preprocessing phase**, date features were converted to datetime format and set as the index for time-series handling. Scaling techniques were applied to normalize feature values, and lag features (previous stock prices) were created to serve as predictors.

Various regression models were implemented, such as **Linear Regression**, **Decision Tree Regressor**, **Random Forest Regressor**, and **Support Vector Regressor (SVR)**. These models were trained to predict future stock closing prices based on historical input features. Their performances were evaluated using metrics like **Mean Squared Error (MSE)**, **Mean Absolute Error (MAE)**, and **R-squared (R²)**. Random Forest and SVR showed the most promising results, accurately capturing stock price trends.

The final results demonstrated that machine learning models could predict future prices with reasonable accuracy, although extreme market fluctuations remain challenging. Visual comparisons between predicted and actual prices confirmed that the models were effective in identifying overall trends.

In conclusion, this project shows the potential of using machine learning for stock price forecasting. For further improvements, future work could include incorporating external data like news sentiment, applying advanced models such as LSTM networks, and building a real-time prediction dashboard to enhance decision-making support.
